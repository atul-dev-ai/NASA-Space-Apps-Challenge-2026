# Mars Exploration Through NASA Data

## 🚀 Project Overview

This project is being developed as part of a NASA-themed hackathon. Our goal is to explore Mars using publicly available NASA mission data and transform scientific information into practical knowledge.

The project aims to make Mars exploration data easier to understand through an interactive and user-friendly platform. Users will be able to explore rover observations, environmental conditions, and other scientific information collected by NASA missions.

**Project Status:** Initial Setup / Development in Progress

## 🎯 Objectives

* Explore real scientific data collected by NASA's Mars missions.
* Present complex scientific information in a simple and understandable format.
* Help users learn about the Martian environment and surface conditions.
* Develop an interactive platform for exploring Mars rover data.
* Demonstrate how open space science data can be transformed into useful educational insights.

## 🛰️ NASA Data Sources

Our project plans to use publicly available data from the following NASA missions and instruments:

* **Perseverance MEDA:** Environmental and weather measurements on Mars.
* **Curiosity REMS:** Environmental monitoring and weather observations.
* **InSight:** Mars lander data, including seismic and environmental observations.
* **Curiosity RAD:** Radiation measurements collected by the Curiosity rover.
* **NASA Open Data:** Additional publicly available scientific datasets, depending on project requirements.

Data sources will be verified during development to ensure that the selected datasets provide the information required by our project.

## 💡 Planned Features

* Explore publicly available Mars mission datasets.
* Display environmental measurements and scientific observations.
* Organize scientific data into understandable visualizations.
* Provide an easy-to-use interface for exploring Mars.
* Present useful information and educational insights based on available data.

*Note: These features are planned and have not necessarily been implemented yet.*
